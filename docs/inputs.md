# Input checklist

Paths are relative to the repository root. Supply genuine scientific inputs;
empty placeholders validate only a DAG and cannot run analyses. Exact cohort
paths, metadata columns and reference versions are in `workflow/config/*.yaml`.
The clone includes GTEx SampleAttributesDS; most other data are deliberately
excluded from Git. Symlinks to existing shared inputs are acceptable if compute
nodes can read them; put all new results in your own writable checkout.

## Automatic downloads

The selected target downloads ARCHS4 v2.5, GTEx v8 expression, recount2,
configured GEO/EBI projection datasets, DrugBank, and Ensembl references as
needed. Azimuth and ARCHS4 Cell-lines also have download rules. The Enrichr
GO:BP prior and checksum-verified org.Hs.eg.db GO:BP evaluation GMT are distinct
and generated by separate rules. Do not substitute one for the other.

## Manual inputs by phase

**Benchmark:** raw pseudobulk cohorts and fixed cohort exports, CellMarker and
Allen Brain Atlas references, `data/archs4/GTEx_Tissues_pathMat.rds`, GTEx
xCell scores, and cell labels for figures.
**ARCHS4 biology:** MSigDB/CellMarker/tissue references, gene lengths,
PhenoPLIER and PhenomeXcan, drug–disease and CRISPR references, plus configured
projection inputs. Cross-dataset projection checks also build pseudobulk and
GTEx prerequisites; phase 2 is not restricted to ARCHS4 raw data.

## Cohort configuration

`workflow/config/pseudobulk.yaml` lists each cohort's raw matrix, metadata,
barcode/feature paths, donor IDs, label mappings, and filtering rules. With
`build_pseudobulk: false`, both the fixed pseudobulk exports and the raw cells
are required for the full benchmark (the raw cells feed projections/donor-bulk).
Do not change this flag to bypass unavailable fixed cohort selections.

The raw cohorts are Brain Mathys 2023, Brain Xiong 2023, Heart Datar 2026,
PBMC 1k1k, PBMC Perez 2022, and Lung Sikkema 2023. Obtain their exact exports
from the data provider or study authors under the applicable access conditions.
Some file provenance/access links were not recorded; request these inputs from
the repository authors before starting a full reproduction. The workflow cannot
reconstruct unavailable manual references or guarantee equivalent cohorts from
an arbitrary current download.

## Projection inputs

`workflow/config/projections.yaml` records download URLs and local inputs for
GEO/EBI cohorts, cytokine/monocyte/placenta projections and their benchmarks.
`workflow/config/cell_type_analysis.yaml` and `donor_bulk.yaml` contain the
additional label/path mappings. Treat these configuration files as the exact
input inventory when running selected downstream analyses.

## Historical runtime evidence

The original seven-day GTEx CoGAPS non-convergence record is committed under
`references/runtime/` and used only for the censored historical annotation.
New timing measurements are computed by the timing rules. No successful CoGAPS
GTEx fit is claimed or fabricated.
